# AGENTS.md - Руководство и системные правила для ИИ-агентов

## Описание проекта
Модульный комбайн для Linux (X11 и Wayland) для скриншотов, экранной записи видео/GIF и быстрого редактирования аннотаций. Приложение сидит в системном трее и использует внешние системные утилиты вместо изобретения велосипедов.

## Стек и архитектурные решения
* Базовый язык: Python 3.11+
* Графический фреймворк: PySide6 (Qt6)
* Обработка и запись медиа: FFmpeg (через внешний процесс QProcess / subprocess)
* Захват видео/скрина: xdg-desktop-portal (PipeWire) как основной бэкенд, x11grab и grim/slurp как фоллбэк
* Аудио: PulseAudio / PipeWire (захват монитора системы и микрофона)
* Хоткеи: D-Bus порталы (Wayland) и нативный перехват через pynput (X11)

## Жесткие правила разработки (CRITICAL CONSTRAINTS)
* Никаких блокировок UI: Любые вызовы FFmpeg, работа с порталами и файловые операции проводятся строго в отдельных воркерах (QThread) или асинхронно. Главный GUI-поток никогда не должен подвисать.
* Никаких самописных кодеров: За всю работу со сжатием, конвертацией, нарезкой и созданием палитр для GIF отвечает строго бинарник FFmpeg.
* Корректная остановка FFmpeg: Процесс записи останавливается передачей символа "q" в stdin процесса, чтобы контейнеры MKV/MP4 корректно финализировали заголовки. Никаких жестких kill -9 без острой необходимости.
* Экранирование: Все аргументы командной строки и пути к файлам должны безопасно паковаться в списки аргументов без сборки команд через небезопасную склейку строк.

## Требования к коду и комментированию
* Все ключевые операции и логические развилки внутри кода должны быть подробно закомментированы.
* Комментарии должны быть строго обезличенными (запрещено использовать слова "я", "мы", "ты", "автор").
* Придерживаться модульной архитектуры:
  - core/ : настройки, конфигурация, обработка хоткеев
  - capture/ : логика взаимодействия с PipeWire, X11, аудиоисточниками
  - encoder/ : профили кодирования, генератор флагов FFmpeg, контроллер подпроцесса
  - editor/ : графический холст аннотаций скриншотов
  - ui/ : трей, диалоги настроек, оверлеи
