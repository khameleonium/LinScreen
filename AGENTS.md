# AGENTS.md - Руководство и системные правила для ИИ-агентов

## Описание проекта
LinScreen — единая программа для Linux, работающая и в X11, и в Wayland: снимки экрана, запись видео/GIF и редактор аннотаций в системном трее. Набор модулей графической системы выбирается при запуске по типу сессии; общее ядро одинаково для обеих систем.

## Архитектура
* `backends/base.py` — общий интерфейс графической системы (снимок, оверлей, источник видео, рамка записи, панель записи, горячие клавиши, буфер обмена).
* `backends/x11/` — прямой доступ к X-серверу: снимок средствами Qt, запись x11grab, дерево окон python-xlib, клавиши pynput.
* `backends/wayland/` — порталы xdg-desktop-portal (Screenshot, ScreenCast, GlobalShortcuts), запись PipeWire → GStreamer → FIFO → FFmpeg, скрипты KWin, рамка через XWayland.
* `backends/__init__.py` — выбор набора: `XDG_SESSION_TYPE`, либо явно `--platform x11|wayland` / `LINSCREEN_PLATFORM`. Модули невыбранного набора не импортируются.
* Общее ядро: `app.py`, `core/`, `capture/` (режимы, мониторы, звук, объекты под курсором), `encoder/`, `editor/`, `ui/`.

## Жесткие правила разработки (CRITICAL CONSTRAINTS)
* Платформенный код — только в `backends/x11` или `backends/wayland`. В общем ядре никаких проверок «если X11 / если Wayland»: различия выражаются методами интерфейса `Backend`.
* Наборы модулей не импортируют друг друга. Исключение — вспомогательный процесс рамки Wayland, который сам работает через XWayland.
* Никаких блокировок UI: вызовы FFmpeg, GStreamer, D-Bus и файловые операции — только асинхронно (QProcess, `core.workers.run_async`).
* Никаких самописных кодеров: всё кодирование — бинарник FFmpeg; GStreamer лишь доставляет кадры из PipeWire.
* Корректная остановка FFmpeg символом "q" в stdin; в Wayland кадры идут через FIFO, stdin свободен.
* Аргументы командной строки — только списками.
* Недостающие компоненты: по возможности вкладываются в AppImage, иначе программа сообщает о них и предлагает установить (окно «Компоненты системы»).

## Требования к коду и комментированию
* Ключевые операции и логические развилки подробно комментируются.
* Комментарии строго обезличенные (без «я», «мы», «ты», «автор»).
* Любая строка интерфейса оборачивается в `tr()` и заносится в `locale/en.json`.

## Команды для локальной проверки
* Запуск: `.venv/bin/python main.py` (явный выбор: `--platform x11` / `--platform wayland`)
* Самопроверка: `.venv/bin/python main.py --check`
* Тесты: `.venv/bin/python -m unittest discover -s tests -t .`
* Линтер: `.venv/bin/python -m flake8 .`
* Типы: `.venv/bin/python -m mypy .`
* Сборка: `./build.sh` → `dist/LinScreen-x86_64.AppImage`
