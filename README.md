# LinScreen

Комбайн для Linux: снимки экрана, запись видео и анимаций, редактор аннотаций.
Работает в системном трее, опирается на готовые системные компоненты
(FFmpeg, PulseAudio/PipeWire, xdg-desktop-portal) вместо собственных кодеков.

## Запуск

Готовый файл `dist/linscreen` запускается двойным щелчком и не требует ни
Python, ни Qt, ни установленного ffmpeg — всё вложено внутрь. Главного окна
нет: значок появляется в системном трее, одиночный щелчок по нему делает
снимок выделенной области.

Проверка работоспособности: `dist/linscreen --check` выводит найденный
FFmpeg, доступные кодеки, звуковые источники и состояние составных частей.

Ярлык в меню приложений и автозапуск включаются галочками в
«Настройки → Общие», вручную ничего прописывать не нужно.

## Сборка единого файла

```bash
./build.sh
```

Сценарий создаёт окружение, загружает сборку FFmpeg 8.1 и собирает
`dist/linscreen` (около 140 МБ). Вложенная сборка FFmpeg выбрана с
поддержкой PulseAudio и SVT-AV1, зависит только от glibc и работает в
любом современном дистрибутиве. Облегчённый вариант, использующий
системный ffmpeg, собирается так:

```bash
LINSCREEN_BUNDLE_FFMPEG=0 ./build.sh
```

## Запуск из исходных текстов

```bash
sudo apt install ffmpeg libxcb-cursor0
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/python main.py
```

### Ограничения записи в Wayland

Путь «портал ScreenCast → PipeWire → FFmpeg» реализован, но для работы
требуются два условия:

* бэкенд портала с интерфейсом `ScreenCast` — пакеты `xdg-desktop-portal-gnome`,
  `-kde`, `-wlr` или `-hyprland` (сборки `-gtk` и `-xapp` его не содержат);
* FFmpeg версии 7.1 или новее — в нём появился фильтр `pipewiregrab`.

При отсутствии любого из условий пункты записи в меню остаются недоступными,
а приложение сообщает конкретную причину. Снимки экрана в Wayland работают
через портал `Screenshot` без дополнительных условий.

## Редактор аннотаций

Открывается сразу после снимка, если это не отключено в настройках.
Крупный снимок вписывается в окно, масштаб меняется колесом мыши.

| Действие | Клавиши |
|---|---|
| Выбор инструмента | `1`…`7` в порядке кнопок на панели |
| Удалить выбранную аннотацию | `Delete` |
| Отменить, вернуть | `Ctrl+Z`, `Ctrl+Shift+Z` |
| Копировать результат и закрыть | `Ctrl+C` |
| Сохранить и закрыть | `Ctrl+S` |
| Сохранить как | `Ctrl+Shift+S` |
| Закрыть без сохранения | `Esc` |

Готовые аннотации перемещаются мышью. Размытие необратимо уничтожает
содержимое выбранной области, а не закрывает его сверху.

## Горячие клавиши

| Действие | Сочетание по умолчанию |
|---|---|
| Снимок области | `Print` |
| Снимок всего экрана | `Shift+Print` |
| Снимок активного окна | `Alt+Print` |
| Начать запись области | `Ctrl+Alt+R` |
| Пауза записи | `Ctrl+Alt+P` |
| Остановить запись | `Ctrl+Alt+S` |

Изменяются в «Настройки → Клавиши». Перехват в X11 не монопольный: если
клавиша уже занята другой программой (например, Flameshot или штатным
снимком экрана рабочего стола), сработают обе. В этом случае комбинацию
следует сменить либо освободить в конфликтующей программе.

## Структура

```
core/     настройки, определение сессии, хоткеи, автозапуск, фоновые вызовы
vendor/   статическая сборка ffmpeg для вложения в исполняемый файл
capture/  захват экрана (x11grab, Qt, grim), порталы D-Bus, звуковые устройства
encoder/  профили FFmpeg, поиск бинарника, контроллер процессов, сохранение картинок
editor/   графический холст аннотаций
ui/       трей, оверлей выделения, панель записи, настройки, журнал
tests/    модульные проверки на unittest
app.py    связывание модулей в рабочий цикл
main.py   точка входа, режимы --check и --version
linscreen.spec  описание сборки единого исполняемого файла
```

Файл настроек: `~/.config/linscreen/config.json`. Повреждённый файл не мешает
запуску: значения возвращаются к исходным. Запись автозапуска создаётся в
`~/.config/autostart/linscreen.desktop` и ссылается на текущий интерпретатор,
то есть на виртуальное окружение проекта.

## Диагностика

Пункт «Журнал…» в меню трея показывает команды, переданные FFmpeg, и его
вывод; он же дублируется в файл `~/.cache/linscreen/linscreen.log`.
Необработанные ошибки записываются в `~/.cache/linscreen/crash.log`.
Там видно точную причину отказа записи. Окно настроек на вкладке
«Общие» показывает найденный бинарник FFmpeg, его версию и перечень
недостающих возможностей сборки.
