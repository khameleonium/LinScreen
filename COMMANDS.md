# LinScreen: команды запуска и управления

Все команды выполняются из каталога программы:

```bash
cd ~/Project/LinScreen
```

## Запуск

```bash
./dist/LinScreen-x86_64.AppImage       # готовый образ
.venv/bin/python main.py               # из исходных текстов
```

Графическая система (X11 или Wayland) выбирается автоматически. Явный выбор:

```bash
./dist/LinScreen-x86_64.AppImage --platform x11
./dist/LinScreen-x86_64.AppImage --platform wayland
```

## Диагностика

```bash
./dist/LinScreen-x86_64.AppImage --check     # самопроверка: сессия, FFmpeg, порталы, модули
./dist/LinScreen-x86_64.AppImage --version   # версия программы
```

## Команды работающему экземпляру

Эти же команды можно назначить на клавиши в настройках рабочего стола.

```bash
./dist/LinScreen-x86_64.AppImage --screenshot          # снимок области
./dist/LinScreen-x86_64.AppImage --screenshot-full     # снимок всего экрана
./dist/LinScreen-x86_64.AppImage --screenshot-window   # снимок окна под курсором
./dist/LinScreen-x86_64.AppImage --record              # запись области: старт и стоп
./dist/LinScreen-x86_64.AppImage --pause               # пауза и продолжение записи
./dist/LinScreen-x86_64.AppImage --settings            # окно настроек
./dist/LinScreen-x86_64.AppImage --check-system        # окно «Компоненты системы»
./dist/LinScreen-x86_64.AppImage --quit                # выход из программы
```

Если программа не запущена, команда запускает её и сразу выполняет
действие. Повторный запуск без ключей при работающей программе открывает
окно настроек.

## Удаление программы из системы

```bash
./dist/LinScreen-x86_64.AppImage --uninstall           # убрать ярлыки, автозапуск, значок,
                                                       # сочетания в настройках KDE и GNOME,
                                                       # разрешения на захват экрана
./dist/LinScreen-x86_64.AppImage --uninstall --purge   # то же, плюс настройки и журналы
```

То же делает кнопка «Настройки» → «Общие» → «Удалить программу из
системы…». Работающая программа при этом завершается. Сам файл программы
не удаляется — его после этого можно просто стереть.

## Проверка кода и сборка

```bash
.venv/bin/python -m unittest discover -s tests -t .   # тесты
.venv/bin/python -m flake8 .                          # стиль
.venv/bin/python -m mypy .                            # типы
./build.sh                                            # сборка dist/LinScreen-x86_64.AppImage
```

## Файлы программы

| Что | Где |
|---|---|
| Настройки | `~/.config/linscreen/config.ini` |
| Журнал работы | `~/.cache/linscreen/linscreen.log` |
| Отчёты о сбоях | `~/.cache/linscreen/crash.log` |

## Замечания

* В KDE Plasma сочетания добавляются в «Параметры системы» → «Комбинации
  клавиш» → «LinScreen». Главные — сочетания в настройках программы: они
  применяются при каждом запуске, а изменения, сделанные в «Параметрах
  системы», переносятся в настройки программы автоматически. Если клавиша
  занята другим приложением (например, Spectacle), программа сообщит,
  каким именно.
* В GNOME до версии 48 сочетания добавляются в «Настройки» → «Клавиатура» →
  «Комбинации клавиш» → «Дополнительные комбинации клавиш» (записи
  «LinScreen: …») и так же переносятся в обе стороны. Клавиши, занятые
  самим GNOME (например, `Print`), нужно сначала освободить в его настройках.
* В X11 программа сразу занимает сочетания клавиш из настроек (`Print`,
  `Ctrl+Print` и др.). Если `Print` занят другой программой (например,
  Flameshot), сработают обе.
